🎯 GoalPlanner

**GoalPlanner** is an Angular application designed to help users plan, prioritize, and track their goals and projects. Ideal for personal productivity, schoolwork, or professional task management.
📦 Features
- ✅ Create and edit goals/projects
- ⏳ Set deadlines and receive reminders
- 🔼 Prioritize tasks (High, Medium, Low)
- 📅 Visualize goals over time
- 🌙 Light & dark theme support
- 🛎️ Daily reminders with motivational messages

🚀 Getting Started
1. Clone the repository
   git clone https://github.com/Gayand-soualplanner.git
   cd goalplanner

2. Install dependencies
   npm install
   
3. Start the development server
   ng serve
5. Navigate to localhost in your browser.
  
🧰 Technologies Used
Angular
TypeScript
SCSS / CSS
RxJS
Angular CLI

Build for Production
ng build --configuration production
