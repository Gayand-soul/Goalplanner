🎯 GoalPlanner 
An Angular-based task management application to organize and track your goals efficiently. Deployed via GitHub Pages.
https://gayand-soul.github.io/Goalplanner/

✨ Features
- Add/delete tasks
- Responsive design (mobile & desktop)
- Modern Angular architecture
- GitHub Pages hosting

🚀 Deployment
This app is automatically deployed to GitHub Pages from the `gh-pages` branch:
Build & deploy commands:
ng build --configuration production --base-href "/Goalplanner/"
npx angular-cli-ghpages --dir=dist/goalplanner/browser

🛠 Development
Prerequisites
-Node.js v16+
-Angular CLI- version 19
-Git

Setup:
1. git clone https://github.com/Gayand-soul/Goalplanner.git
    cd Goalplanner

2. Install dependencies: npm install
3. Run locally: ng serve
4. Open http://localhost:4200
